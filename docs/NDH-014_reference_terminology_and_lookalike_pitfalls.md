# Reference NDH-014: "Tumor", "Mass", "Cancer" are NOT the same word
Northgate Demo Hospital Tumor Board Education Series | SYNTHETIC DEMO DATA, fictional reference, not a real publication

## Core definitions
- MASS, LESION, NODULE: descriptive imaging words. They say nothing about cause.
- TUMOR / NEOPLASM: abnormal tissue growth. Can be benign, borderline or malignant. A tumor is not automatically cancer.
- BENIGN TUMOR: does not invade or spread (NDH-001 hamartoma, NDH-004 fibroadenoma, NDH-009 meningioma, NDH-012 hemangioma). May still need treatment because of size or location.
- BORDERLINE TUMOR: between benign and malignant, can recur locally (NDH-005 phyllodes).
- IN SITU CARCINOMA (for example DCIS in breast): abnormal cells that have not crossed the basement membrane. It is NOT benign. It is treated as an early cancer-type disease (stage 0).
- MALIGNANT TUMOR / CANCER: invades tissue and can metastasize (NDH-002, 006, 008, 010, 013).
- PRIMARY vs METASTATIC: where the cancer began versus where it spread. A brain lesion in a cancer patient is not automatically a primary brain tumor.
- NON-NEOPLASTIC MIMIC: infection or inflammation that imitates a tumor (NDH-003 fungal granuloma, NDH-011 brain abscess). Not a tumor at all.
- RECLASSIFIED LOW-RISK NEOPLASM: NIFTP (NDH-007), no longer called carcinoma since 2016.

## Phrases that mislead
| Phrase | Trap |
| "stable" | Stable for years supports benign (NDH-001). Stable on treatment says nothing about benign. |
| "papillary" | Can describe nuclei only (NIFTP) or true carcinoma (NDH-008). |
| "well-circumscribed" | Typical of benign, but aggressive cancer can be smooth (NDH-006). |
| "PET avid" | Cancer, infection and inflammation all light up (NDH-003). |
| "enhancing" | Describes contrast behavior; pattern matters: fill-in (NDH-012) vs washout (NDH-013). |
| "ring-enhancing" | Glioblastoma (NDH-010), metastasis, or abscess (NDH-011). |
| "favor fibroadenoma" | A core biopsy may under-sample phyllodes (NDH-005). |
| "benign" | Benign does not mean harmless or untreated (NDH-009). |
| "managed by surveillance" | Some small cancers are watched; that does not make them benign. |
