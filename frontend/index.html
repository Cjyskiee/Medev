Privacy notes

  • The public demo uses fictional, synthetic records only. Do not enter real patient information.
  • The model API key stays on the backend and is never sent to the browser.
  • Retrieved excerpts for a question are sent to the organizers' model API to generate the summary.
  • Search history is stored locally in backend/data/history.json. Clear it from Chat History.
  • MedEvidence is a research prototype. It is not clinically validated and gives no diagnosis or treatment advice.
